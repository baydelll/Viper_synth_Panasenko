# VIPER SYNTH — HTML/CSS/JS

Дизайн воссоздан по `viperready.svg`: все рамки, надписи, переключатели и ползунки выполнены HTML/CSS; в `assets/viper-logo.png` находится только логотип, извлечённый из SVG. Размер исходного макета 2560×1440; интерфейс масштабируется под окно.

## Как запустить
1. Распакуйте ZIP и откройте папку в VS Code.
2. Запустите `index.html` через **Live Server** или иной локальный HTTP-сервер.
3. Нужен доступ к CDN `cdnjs.cloudflare.com` для библиотеки Tone.js 14.8.49.
4. Нажмите ▶ — браузер разрешает запуск звука только после пользовательского взаимодействия.

## Функции
- Синтезатор 1 — `Tone.FMSynth`, синтезатор 2 — `Tone.DuoSynth`.
- У каждого: отдельный выбор формы волны, ADSR, Freeverb, PingPongDelay и Chorus.
- Центральные переключатели меняют форму обработки общего сигнала, `volume` управляет общим уровнем.
- Кнопка ▶/❚❚ запускает и приостанавливает исходную мелодию без её изменения.
- Визуализатор реагирует на аудиосигнал каждого синтезатора.

## Структура
- `index.html` — семантические элементы управления
- `style.css` — верстка по SVG
- `javascripts/synthesizer.js` — исходная мелодия и аудиодвижок
- `javascripts/script.js` — UI/события/визуализатор
- `assets/viper-logo.png` — логотип, не интерфейс
- `fonts/PixeloidSans.ttf` — локальный шрифт
